# aibox 独立部署方案

状态：2026-10-27 用户选择保留 `https://usehooo.com/aibox/`。本文是实施依据，尚未部署；路径需在首次接入时核验。

## 目标与范围

aibox-web 保持独立仓库和文件包。Nginx 直接提供静态页面，主站继续处理商城、订单和 API。普通 aibox 发布不得构建、重启、覆盖主站，也不得修改数据库、支付配置或 V3 资源。

页面地址统一为 `/aibox/`、`/aibox/en/`、`/aibox/init/`。无尾斜杠地址重定向到相应规范地址，保留查询参数；不存在的资源返回 404，不回退到主站或首页。主站入口使用普通链接。

## 目录与制品

建议服务器目录（尚未创建）：

```text
/opt/aibox/
├── releases/<完整提交SHA>/
└── current -> releases/<当前SHA>/
```

每个版本附带文件摘要与来源提交记录；不覆盖已有版本目录。发布包仅包含三份页面、assets、favicon.svg、已脱敏的 init/cast.js 和实际采用的分享图。维护文档、Git、工具、配置及原始录制不公开。子目录 robots.txt 不能替代域名根部 robots.txt；如需调整主站索引策略，另作主站变更。

HTML 使用短缓存或重新验证；CSS、JS、录制数据采用版本化 URL，旧版本资源在保留期内可访问。只加查询串后覆盖同名文件无法保证旧页面读到旧资源。`tools/package.py` 已实现提交白名单打包和资源版本映射，`tools/install_release.py` 已实现摘要核验、原子选择及回退；本地测试已通过，生产尚未执行。

## 首次接入

1. 核验实际主站 SHA、Nginx 配置、资源路径和服务身份；确认 aibox 路径不与主站/V3 重叠。
2. 将 aibox 路由纳入受管理的 Nginx 配置。现有发布检查要求服务器、可信管理包和主站候选配置一致，不能临时手改服务器绕过校验。
3. 固定静态文件映射与缓存规则，关闭目录列表，保留安全响应头；验证目录与符号链接的读权限。发布身份只能写 aibox 范围，不授予主站或通用 Nginx 修改权限。
4. 先验证完整新版本，再受控应用配置并平滑 reload。记录原配置及兼容回退步骤；旧主站版本回退也需核查共享配置兼容性。
5. 如需要，在主站单独增加导航链接。页面独立，不直接继承主站布局或 CSS。

## 后续独立更新与回退

1. 从确定的提交生成静态包，校验白名单、路径、摘要和页面链接。
2. 上传到新的 aibox 版本目录，不对活动目录执行覆盖同步或删除。
3. 验证新目录中的三个页面、资源、语言切换、移动端与深浅色显示。
4. 在同一文件系统内原子替换 current 链接。普通发布无需重新加载 Nginx，也不调用主站 release.sh。
5. 检查公网页面与版本标识；失败则切回上一个已验证版本。只回退 aibox 文件，不恢复主站数据库。
6. 至少保留活动版与上一已验证版；结合缓存有效期保留旧资源。清理前确认无活动引用，不删除唯一恢复副本。

## 验收

- `/aibox/`、英文页、录制页、无尾斜杠跳转和缺失资源响应符合预期。
- 静态文件不经 Next.js；aibox 更新前后主站活动 SHA、进程及主要页面正常。
- 在隔离测试环境演练主站更新、aibox 更新和双方回退，证明互不覆盖。
- 模拟旧页面加载新发布时的资源请求，确保版本资源仍可访问。
- 商城购买、支付、订单与售后是单独任务。宣传页更新不自动创建 SKU 或改变定价与权益。

## 隔离边界

同服务器仍共享磁盘、网络与 Nginx；同域名路径仍处于同源环境，目录隔离不能约束浏览器脚本访问同源接口。维持主站鉴权与请求校验，不在 aibox 引入未审第三方脚本或根作用域 Service Worker。需要更强安全或故障隔离时，再评估子域名和独立托管。

## 打包与选择版本

```bash
python3 tools/package.py --revision <40位提交SHA> --output <全新输出目录>
python3 tools/install_release.py --root /opt/aibox --revision <40位提交SHA> --package <已上传包目录>
# 选择一个已经保留并验证的旧版本，不覆盖内容
python3 tools/install_release.py --root /opt/aibox --revision <旧40位提交SHA>
```

只从指定 Git 提交读取白名单，不包含维护文档、Git、环境文件或工具。包中的 HTML 使用 `/aibox/_assets/<SHA>/...`，固定映射到 `/opt/aibox/releases/<SHA>/...`。旧资源缓存最长一年，保留期不得短于缓存有效期；这些纯静态文件体积小，不自动清理。

WHY AIBOX

真实 IP、系统、代码，
分别筑起安全防火墙。

aibox 将终端工作环境与日常使用环境分开管理，减少网络配置相互干扰，并限制容器可访问的项目目录。隔离能力需结合实际配置验证，不代表账号不会受到限制。

01

告别网络打架，办公社交两不误

无需开启烦人的全局代理。电脑宿主机依然走原有直连或办公内网，微信、钉钉消息畅通无阻；只有沙箱内的 AI 流量走指定的海外专网，互不干扰。

02

独立网络出口，便于排查连接

容器通过指定节点联网，并设计了 Fail-Closed 断线阻断机制。是否存在 DNS 或其他旁路泄漏，应在实际环境中验证。

03

严格目录授权，保护宿主机隐私

只有你明确授权的项目目录对容器可见，支持内核级只读（ro）挂载。未挂载的宿主机目录通常不可见；已授权目录中的文件仍可能被读取，读写挂载中的文件也可能被修改或删除。

      ARCHITECTURE & TECH HIGHLIGHTS

      硬核技术架构：
      双容器网络命名空间隔离。

      Claude Code 在工作区容器（workspace）中运行，网络通信完全交由独立的网关容器（gateway）托管。两边通过 Linux 共享网络命名空间打通，实现极客级的安全闭环。

      🛡️ 双容器 NetNS 权限隔离

      工作区容器被剥夺全部网络特权（无 NET_ADMIN、无 NET_RAW），即使 Prompt 注入执行 sudo iptables -F 也无法破坏防火墙规则。

      ⚡ Fail-Closed 与 Kill Switch

      容器启动即默认拒绝（Default DROP）。节点意外断连时瞬间静默阻断，杜绝任何直连回退；强制 empty-fallback: REJECT 杜绝直连。

      🌐 Fake-IP DNS 与 IPv6 熔断

      内核级拦截所有 53 端口查询并走 DoH 加密隧道；封禁 Docker 内置的 127.0.0.11 宿主机借道转发；sysctl + ip6tables 双重切断 IPv6 旁路。

      📂 宿主机 UID:GID 动态对齐

      容器自动识别宿主机用户真实 UID:GID（macOS 501:20），AI 生成的文件在宿主机查看权限完全一致，不产生 root 文件锁死问题。

      💻 进程替换与 Tmux 长任务

      输入 aibox claude 直接通过 exec 替换 Shell，Ctrl+C 精准传递；内置 aibox tmux，关闭终端后可恢复会话；宿主机休眠、关机或容器停止时，任务不能保证继续运行。

      🚀 复用 Docker 运行环境

      复用已有 Docker 运行环境。内存与启动时间取决于系统、运行时、镜像缓存和任务负载；首次下载与构建不计作冷启动实测。

      FAQ & BEST PRACTICES

      动手之前，
      你可能想问。

      💡 aibox 是否使用了指纹浏览器？如何实现全链路防关联？

      明确技术事实：Claude Code 是基于终端的 Node.js CLI 工具，底层直接发起网络 API 交互，本身并不运行在网页浏览器中，因此不存在内置 Web 指纹浏览器的载体。aibox 针对终端实现了系统级时区与语言 Locale 自动对齐、环境脱敏与网络隔离。

      最佳实践推荐：首次运行 aibox claude 时终端会打印一段 OAuth 网页授权链接。如果您对防风控有极致要求，推荐将该链接复制到配置了相同纯净节点的指纹浏览器（如 AdsPower、Hubstudio、Camoufox）中打开完成登录，再把授权码粘回终端，从而实现“Web登录端（指纹防关联）+ 终端沙箱（aibox专网）”的双重闭环！

      使用 aibox 保证 100% 不封号吗？

      没有任何工具能承诺“绝对防封”。Anthropic 官方风控涵盖节点历史信誉、账号注册来源、支付卡属地、输入内容违规等多重因素。aibox 专注为您构建最纯净的“网络隔离与环境防穿透”底座。如需订阅与补开服务，可查看上方 Claude Pro 安心订阅包：包含一个月 Pro 直充，首次到账起 30 天内封号最多补开两次，补开不重新计时；价格与可售状态同步商城。

      必须自己准备代理节点吗？

      开源自助与配置协助需自备节点；VPS 网络环境部署包包含首月 VPS 使用，到期联系客服续费，价格另行确认。开源工具本身不附带免费节点或代理。您可以使用常用的订阅链接（Clash、v2rayN、Shadowrocket 等格式均可自动识别），或自建 WireGuard 节点。

      远程代装会索取我的 Claude 账号密码吗？

      绝对不会。整个代装过程全程远程透明、可审计。在最后的登录环节，技术专家会暂停屏幕共享或等待您在本地终端中亲自输入授权凭据，严禁代登，保障您的数字资产安全。

      支持在哪些操作系统上运行？

      完美支持 macOS（Intel / Apple Silicon 芯片，推荐使用 OrbStack 或 Docker Desktop）、原生 Linux（Ubuntu / Debian 等），以及 Windows 系统（需开启 WSL2 集成）。

      我的网络节点断了，会不会偷偷跳回国内直连？

      绝对不会。aibox 内置内核级 Fail-Closed 防火墙规则，节点一旦中断，沙箱内流量立即断网静默丢弃，绝不会有任何数据包走宿主机直连泄露真实 IP。节点恢复后约 3 秒自动重新联网。

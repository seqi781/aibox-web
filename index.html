WHY AIBOX

真实 IP、系统、代码，
分别筑起安全防火墙。

aibox 将终端工作环境与日常使用环境分开管理，减少网络配置相互干扰，并限制容器可访问的项目目录。隔离能力需结合实际配置验证，不代表账号不会受到限制。

01

告别网络打架，办公社交两不误

无需开启烦人的全局代理。电脑宿主机依然走原有直连或办公内网，微信、钉钉消息畅通无阻；只有沙箱内的 AI 流量走指定的海外专网，互不干扰。

02

独立网络出口，便于排查连接

容器通过指定节点联网，并设计了 Fail-Closed 断线阻断机制。是否存在 DNS 或其他旁路泄漏，应在实际环境中验证。

03

严格目录授权，保护宿主机隐私

只有你明确授权的项目目录对容器可见，支持内核级只读（ro）挂载。未挂载的宿主机目录通常不可见；已授权目录中的文件仍可能被读取，读写挂载中的文件也可能被修改或删除。

      ARCHITECTURE & TECH HIGHLIGHTS

      硬核技术架构：
      双容器网络命名空间隔离。

      Claude Code 在工作区容器（workspace）中运行，网络通信完全交由独立的网关容器（gateway）托管。两边通过 Linux 共享网络命名空间打通，实现极客级的安全闭环。

      🛡️ 双容器 NetNS 权限隔离

      工作区与网关容器分工运行；工作区默认不授予 NET_ADMIN、NET_RAW 等网络管理权限，减少工作负载改动网络规则的风险。实际权限以运行配置为准。

      ⚡ Fail-Closed 与 Kill Switch

      网关按默认拒绝策略配置，节点中断时阻断容器连接。配置完成后，可通过 aibox doctor --full 检查当前环境的断线阻断与恢复表现。

      🌐 DNS 与 IPv6 旁路限制

      由网关集中处理 DNS，并配置 IPv6 与直连限制，减少绕过指定出口的连接路径。不同代理模式与系统环境需分别检查。

      📂 宿主机 UID:GID 动态对齐

      按宿主机用户的 UID:GID 配置工作区文件权限，减少挂载目录产生 root 所有者文件的问题；实际权限表现与宿主系统及 Docker 配置有关。

      💻 进程替换与 Tmux 长任务

      输入 aibox claude 直接通过 exec 替换 Shell，Ctrl+C 精准传递；内置 aibox tmux，关闭终端后可恢复会话；宿主机休眠、关机或容器停止时，任务不能保证继续运行。

      🚀 复用 Docker 运行环境

      复用已有 Docker 运行环境。内存与启动时间取决于系统、运行时、镜像缓存和任务负载；首次下载与构建不计作冷启动实测。

      FAQ & BEST PRACTICES

      动手之前，
      你可能想问。

      浏览器登录也会走 aibox 的专网吗？

      容器与浏览器分别配置。aibox 主要管理容器内的命令行工具流量。宿主机浏览器使用自身网络设置，不会自动继承容器的出口。

      首次授权请按工具提示自行完成，并单独检查浏览器的网络配置。aibox 不包含内置指纹浏览器，也不提供完整机器指纹伪装；账号密码与授权凭据由您自行输入。

      使用 aibox 保证 100% 不封号吗？

      不能保证。aibox 提供独立网络出口与容器环境隔离，账号状态仍受账号自身情况、使用行为与服务规则等因素影响。如需订阅与补开服务，可查看上方 Claude Pro 安心订阅包：包含一个月 Pro 直充，首次到账起 30 天内封号最多补开两次，补开不重新计时；价格与可售状态同步商城。

      必须自己准备代理节点吗？

      需要自备或自行购买网络节点。两项人工服务均可指导选择和配置节点，但不提供 VPS 或网络节点使用时长；开源工具本身也不附带免费节点或代理。请按安装向导提供受支持的订阅链接或节点配置，具体格式以项目文档为准。

      远程代装会索取我的 Claude 账号密码吗？

      绝对不会。整个代装过程全程远程透明、可审计。在最后的登录环节，技术专家会暂停屏幕共享或等待您在本地终端中亲自输入授权凭据，严禁代登，保障您的数字资产安全。

      支持在哪些操作系统上运行？

      面向 macOS、原生 Linux 和 Windows 的 WSL2 环境使用，需先安装并启动兼容的 Docker 运行环境。系统版本、芯片架构与 Docker 模式不同，安装前请对照项目文档确认。

      我的网络节点断了，会不会偷偷跳回国内直连？

      按设计，节点中断时容器连接应被阻断，而不是回退到宿主机直连。建议配置后执行 aibox doctor --full 验证当前环境的阻断与恢复表现；检测失败时应先排查配置。
